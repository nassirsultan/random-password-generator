# Random Password Generator

A clean, minimal client-side web application that generates strong random passwords instantly. Built with vanilla JavaScript, HTML, and CSS — no frameworks or backend required.

## Live Demo

[https://random-password-io.netlify.app](https://random-password-io.netlify.app)

## Tech Stack

- **JavaScript** (Vanilla)
- **HTML5**
- **CSS3**
- **Deployed on Netlify**

## Features

- Generate a strong random password with one click
- Copy to clipboard instantly
- Clean, minimal dark-themed UI
- Fully client-side — no data sent to any server

## Getting Started

### Run Locally

```bash
git clone https://github.com/nassirsultan/random-password-generator
cd random-password-generator
# Open index.html in your browser
```

Or simply open `index.html` directly in any modern web browser — no build step required.

## Why This Project

Demonstrates core JavaScript skills including DOM manipulation, event handling, string operations, and randomization logic without relying on any external libraries or frameworks.
